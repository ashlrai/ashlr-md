Install Ashlr MD

Download for your platform

Choose the package for your operating system from GitHub Releases. The installation guide covers macOS disk images, Windows installers, and Linux deb, rpm and AppImage packages. Follow its platform instructions and prerequisites.

Source: Platform installation instructions

Open your first Markdown file

Launch the app and open a .md file. For terminal use, enable Preferences → Command-line tool → Install mdopen, then run mdopen notes.md. Package installers do not automatically put mdopen on your PATH.

Source: First-run and CLI setup

Set up optional agent integration

Open Preferences → AI agents (MCP) to connect a detected agent. The agent guide includes manual commands, platform paths and AppImage-specific setup. Start with the review workflow to decide which integration you need.

Source: Agent setup guide
