Export Markdown for review and sharing

Choose the format for the recipient

Ashlr MD provides PDF, DOCX and HTML export. PDF uses the operating system print dialog, DOCX is generated in the app, and HTML includes the document styles. Use PDF for a print-oriented review, DOCX for a word-processing handoff, or HTML for a browser-readable copy.

Source: Export implementation and format handling

Prepare a document for export

  1. Install Ashlr MD and open your Markdown file.
  2. Switch to Read view so the rendered document is available.
  3. Open Export, select your format, and choose the destination. For PDF, finish through the operating system print dialog.
  4. Open the result and check headings, tables, diagrams and page breaks before sending it.

The export functions require the rendered .markdown-body element; they report an error when Read view is absent.

Source: Read-view requirement and PDF print flow

Make the output fit the handoff

The export dialog offers template and profile choices. Templates control document styling; profiles post-process HTML for specific destinations. Keep the original Markdown as your editable source and inspect the generated file in the receiving application.

Source: Export dialog choices

Check portability rather than assuming it

The HTML builder inlines document CSS and embeds KaTeX fonts when math is present. That does not establish that every externally referenced asset in your input is portable. Test the exported file with the assets and connectivity your recipient will have.

Source: HTML styling and math font embedding
