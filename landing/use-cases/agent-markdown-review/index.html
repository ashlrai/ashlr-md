Review Markdown written by AI agents

Keep the plan beside the work

When an agent produces a plan or research note, open the file in Ashlr MD and read it before the next change. The bundled mdopen CLI opens Markdown from a terminal, and the Agent Activity drawer can watch an output folder for new files.

Source: Agent workflow guide

Start with one file

  1. Follow the installation guide, then enable Preferences → Command-line tool → Install mdopen.
  2. Run mdopen PLAN.md from your project folder.
  3. Open the Agent Activity drawer with ⌘B on macOS or Ctrl+B on Windows and Linux, and choose the folder your agent writes to.

This is useful when you want to read generated files without connecting an agent to the app.

Source: CLI installation and activity drawer

Add a review loop when you need it

In Preferences → AI agents (MCP), connect a detected agent. The MCP server exposes tools for opening, reading, editing and exporting the live document, plus request_review for requesting human review. Try asking your agent: “Open PLAN.md, add a risks section, then request my review.”

Only open_file starts the app. Other live-document operations require the app to be running. A review request is a workflow step, not a guarantee that generated content is correct.

Source: MCP tools and prerequisites

Choose how much to connect

Use the CLI for opening files, the activity drawer for watching a folder, and MCP when you want an agent to operate on the document. For AppImage installations, use the in-app connection flow to register a stable copy of the sidecar instead of a temporary mount path.

Source: AppImage sidecar setup
