Read Markdown notes from your vault

Open an existing note

Ashlr MD can read Markdown files in an Obsidian vault, resolve wikilinks across the vault, and open linked notes in tabs. Start with a note containing a heading link such as [[project#Next steps]] and an embed such as ![[summary]].

Source: Wikilink syntax and resolution

Set the right vault root

  1. Install Ashlr MD and open a .md file in your vault.
  2. Let the app locate the nearest parent .obsidian folder, or choose a folder in Settings → Vault.
  3. Follow a link to check that it resolves within the intended folder.

Without a vault marker or override, link resolution falls back to the document folder. Saving into an .obsidian configuration folder is refused.

Source: Vault discovery and write guard

Check the limits before adopting a workflow

The documented compatibility layer does not evaluate plugin query blocks such as Dataview or Templater. The vault guide describes canvas viewing as read-only and lists additional limits for block-reference jumps, multi-paragraph comments and frontmatter aliases. Review those limits against your own notes before relying on a rendered view.

Source: Documented compatibility limits

Return to your existing tools

The Open in Obsidian command hands the current note to an installed Obsidian app. The companion Open in Ashlr MD plugin provides the reverse path through a ribbon button, command or context menu. Use these handoffs when a note needs its original workflow.

Source: Companion plugin and handoff
