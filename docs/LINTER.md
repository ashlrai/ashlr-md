# Markdown linter

Ashlr MD ships a small Markdown linter with eleven built-in rules. Each rule is
a pure function over the document text, and most rules carry a fix that returns
the corrected document. The rules live in
[`src/lib/mdlint.ts`](../src/lib/mdlint.ts); this page lists them as that file
defines them.

## Where it shows up today

- **Settings → Linter rules** lists every rule with its label, severity and
  description, and a checkbox to turn it off. Every rule starts enabled; the
  setting stores only the IDs you turn off (`linterConfig.disabledRules`).
  The four rules marked **Default** are the ones the suggestions toast shows.
- **The suggestions toast** (`src/components/LinterToast.tsx`) is the
  component with **Fix** and **Fix all**. It is not mounted anywhere in the
  app as of 0.7.5, so neither the toast nor the editor squiggles that the
  settings panel mentions appear yet. The rules, the fixes and the toast's
  Fix all path are covered by the Vitest suites under `src/lib/mdlint*.test.ts`.

The [autofix guides](#autofix-guides) below describe the toast's behavior,
which is what the tests pin.

## Rules

Severity is the value shown in the settings panel. **Fix** says what the
rule's fix does; "none" means the rule only reports.

| Rule ID | Label | Severity | Default | Fix |
|---|---|---|---|---|
| `frontmatter-required` | Frontmatter required | Warning | | Prepends `---`, `title: `, `tags: []`, `---` and a blank line, in the file's line endings |
| `max-heading-depth` | Max heading depth = 3 | Warning | | Turns an H4 or deeper heading into H3 |
| `no-bare-urls` | No bare URLs | Warning | | Wraps the URL as `[url](url)` |
| `wikilink-targets-exist` | Wikilink targets exist | Error | | None; it cannot create the missing file |
| `no-empty-headings` | No empty headings | Error | | None |
| `no-trailing-spaces` | No trailing spaces | Info | Yes | Removes trailing spaces, keeping an exact two-space hard break |
| `single-h1` | Single H1 heading | Warning | | None |
| `no-consecutive-blank-lines` | No consecutive blank lines | Info | | Keeps the first blank line of the run |
| `orphaned-heading` | No orphaned headings | Warning | Yes | None |
| `invalid-link-target` | No invalid link targets | Warning | Yes | Replaces the destination with `TODO` |
| `missing-alt-text` | Images must have alt text | Warning | Yes | Inserts `TODO: describe image` as the alt text |

Notes from the source:

- An empty document gets no `frontmatter-required` warning. A block closed by
  `...` counts as front matter.
- The heading rules read ATX and setext headings outside front matter, code,
  list items and blockquotes.
- `no-trailing-spaces` and `no-consecutive-blank-lines` skip code blocks.
- `wikilink-targets-exist` runs only when the caller passes the vault's known
  link targets; without them the rule is skipped.
- Fixes compose: each fix receives the current document, and Fix all applies
  fixes from the last offset to the first.
